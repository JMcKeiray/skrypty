Możesz użyć poniższej komendy, aby wykonać skrypt bezpośrednio z GitHuba:  

### Windows
Skrypt "GetPCInfo.ps1" do zbierania informacji o komputerze  
`irm "https://s.yglnk.ovh/GetPCInfo" | iex`

! **Ten skrypt usuwa bieżących użytkowników (windows) i tworzy nowych, nie uruchamiaj jeśli nie wiesz co robisz** !  
`irm "https://raw.githubusercontent.com/JMcKeiray/skrypty/refs/heads/main/bootstrap.ps1" | iex`

### Linux
`curl -s https://raw.githubusercontent.com/eriktron/MojeRepo/main/skrypt.sh | bash`
